# DevTools

A developer toolbox with an Angular frontend and Spring Boot microservices.

```text
DevTools/
  frontend/          # Angular frontend
  gateway-service/   # API gateway
  pom.xml            # Maven aggregator for backend services
```

See [frontend](frontend/README.md) for frontend setup notes and
[gateway-service](gateway-service/README.md) for gateway configuration and commands.

Backend Maven coordinates use `com.devtools`; Java packages use
`com.devtools.gatewayservice`.
